# Student Grade Calculator

## About the Project
This is a simple Python mini-project developed for the Codomax AI & Machine Learning Internship, Module 2.

## Features
- Accepts the student's name.
- Takes marks for five subjects.
- Calculates total marks and average.
- Displays pass or fail status.
- Assigns a grade based on the average.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python student_grade_calculator.py
```
